# 키보드 단축키

Mac 앱과 Windows(Electron) 앱은 같은 키를 같은 뜻으로 써요. Windows 에서는 ⌘ 가 Ctrl, ⌥ 가 Alt 예요.
앱 안에서는 **도움말 › 키보드 단축키** 에서 이 표를 그대로 볼 수 있어요.

표의 원본은 두 곳이고 이 문서와 행·키가 같아야 해요. 하나를 바꾸면 셋을 함께 바꿔요 — 두 앱의 테스트가 이 문서의
Mac·Windows 열과 비교해요.

- Mac: `Core/Sources/ReviewGateCore/Session/ShortcutTable.swift` (검사: `ShortcutTableTests`)
- Windows: `clients/desktop/src/renderer/shortcutTable.ts` (검사: `shortcutTable.test.ts`)

## 권한·계획 카드

메시지 입력란이 비어 있거나 카드에 포커스가 있을 때만 동작해요 — 입력 중에는 동작하지 않아요.

| 동작 | Mac | Windows | 비고 |
|---|---|---|---|
| 한 번 허용 | ⌘↩ | Ctrl+Enter | |
| 세션 동안 허용 | ⌥⌘↩ | Ctrl+Alt+Enter | |
| 거부 | ⌘⌫ | Ctrl+Backspace | |
| 계속 계획하기 | Esc | Esc | 계획 카드 |
| 입력한 지시로 거부하고 계속 | ↩ | Ctrl+Enter | 카드가 기다리는 동안 메시지를 입력했을 때 — 보내기 키 |
| 한 번 허용 · 세션 동안 허용 · 지시와 함께 거부 | 1 / 2 / 3 | 1 / 2 / 3 | 카드에 포커스가 있을 때 — 빨간 카드는 숫자로 허용하지 않아요 |

## ⌘↩ 와 ⌥⌘↩

⌥⌘↩ 는 언제나 ⌘↩ 의 "더 센" 쪽이에요. 메시지를 입력했으면 ⌘↩ 가 보내기(작업 중이면 대기열), ⌥⌘↩ 가 지금 턴을
멈추고 보내기예요. 입력란이 비어 있으면 ⌘↩ 가 가장 오래 기다린 권한 카드를 한 번 허용, ⌥⌘↩ 가 세션 동안 허용이에요.
입력 중에 ⌥⌘↩ 가 카드에 답하는 일은 없어요.

## 터미널처럼 쓰는 메시지 입력란

메시지 입력란은 터미널에서 Claude Code 를 쓰는 것처럼 동작해요(PROTOCOL §44.1).

- **Shift+Tab** 이 권한 모드를 기본 → 편집 바로 허용 → 계획 → 자동 → 기본 순서로 바꿔요. 이 모델에서 자동 모드를 쓸 수 없다고
  엔진이 알려 준 뒤에는 자동을 건너뛰어요. Claude 가 작업 중이면 이번 턴이 끝날 때 바뀌어요. 입력란 밖에서 Shift+Tab 은 예전처럼
  포커스를 앞 칸으로 옮겨요.
- 입력란 바로 아래 한 줄이 지금 모드를 보여 줘요: "⏵⏵ 자동 모드 (shift+tab 전환)", "⏸ 계획 모드 — 승인하면 자동 모드로 돌아가요
  (shift+tab 전환)". Claude 가 스스로 계획 모드에 들어가도 바로 바뀌어요.
- **Esc** 는 팔레트·프롬프트 기록이 먼저 쓰고, 그다음에는 작업 중인 턴을 멈춰요(⌘. / Ctrl+. 와 같아요). 불러온 프롬프트가
  보이는 동안에는 첫 Esc 가 쓰던 글을 돌려주고, 다음 Esc 가 턴을 멈춰요.
- **↑ / ↓** 는 이전·다음 프롬프트를 불러와요. 쓰던 글이 있어도 되고, 그 글은 잃어버리지 않아요 — 가장 최근 프롬프트를 지나
  ↓ 를 누르거나 Esc 를 누르면 돌아오고, 프롬프트를 보내기 전까지 남아 있어요. 불러온 프롬프트를 고쳐도 기록을 오가는 동안
  고친 내용이 남아요. Mac 은 커서가 첫 줄·마지막 줄(화면에 보이는 줄)에 있을 때 불러오고, Windows 는 글이 있으면 ↑ 는 맨 앞,
  ↓ 는 맨 끝에서만 불러와요(첫 번째 누름이 커서를 그리로 옮겨요) — 길게 접힌 문단에서도 화살표로 줄을 옮길 수 있게요.
- **`/btw 질문`** 은 터미널처럼 곁질문이에요(PROTOCOL §56.1). Claude 가 작업 중이어도 바로 물어보고, 도구 없이 지금까지의
  대화로 답해요. 답은 입력란 위에 떠요 — 대화·대기열·프롬프트 기록에는 남지 않아요. Esc 로 닫고(턴을 멈추기 전에), 입력란이
  비어 있으면 ↩ · Space 로도 닫아요. `/btw` 만 입력하면 이 채팅의 마지막 답을 다시 보여 줘요.
- `!` 셸 모드는 없어요(명령은 Claude 에게 부탁해요 — 리뷰를 거치게).

- Windows: 에이전트 패널이 Ctrl+Shift+E 에서 Mac 과 같은 Ctrl+Alt+A 로 바뀌었어요.

- 두 앱: 도움말 › 키보드 단축키 가 이 표를 보여 줘요.
