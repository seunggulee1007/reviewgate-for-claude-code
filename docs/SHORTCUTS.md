# 키보드 단축키

Mac 앱과 Windows(Electron) 앱은 같은 키를 같은 뜻으로 써요. Windows 에서는 ⌘ 가 Ctrl, ⌥ 가 Alt 예요.
앱 안에서는 **도움말 › 키보드 단축키** 에서 이 표를 그대로 볼 수 있어요.

표의 원본은 두 곳이고 이 문서와 행·키가 같아야 해요. 하나를 바꾸면 셋을 함께 바꿔요 — 두 앱의 테스트가 이 문서의
Mac·Windows 열과 비교해요.

> 코드 탐색의 §65 행(정의 미리 보기, 포인터 미리 보기, 다음·이전 참조, 이 파일의 심볼, 프로젝트 심볼)은 Windows 쪽이 먼저
> 넣었어요. Mac 열은 PROTOCOL §65.8 의 키를 적어 둔 자리이고, Mac 앱이 고른 키로 합칠 때 맞춰요 (Core 의 `ShortcutTable.swift`
> 도 그때 같이) — ⌘⇧O·⌘T 는 Mac 에서도 프로젝트 전환·새 채팅이라 겹쳐요.

- Mac: `Core/Sources/ReviewGateCore/Session/ShortcutTable.swift` (검사: `ShortcutTableTests`)
- Windows: `clients/desktop/src/renderer/shortcutTable.ts` (검사: `shortcutTable.test.ts`)

## 프로젝트 없는 창

프로젝트를 열지 않은 창의 세 카드예요 (PROTOCOL §69.4) — Mac 앱과 Windows 앱 모두.

| 동작 | Mac | Windows | 비고 |
|---|---|---|---|
| 새로 시작 · 업무로 시작 · 폴더 열기… | 1 / 2 / 3 | 1 / 2 / 3 | 누르면 바로 열려요 |
| 카드 사이 이동, 표시된 것 열기 | ← → ↑ ↓ ↩ | ← → ↑ ↓ Enter | |

## 시작 화면

프로젝트 창이 열릴 때 보여요 (PROTOCOL §63.4) — Mac 앱과 Windows 앱 모두.

| 동작 | Mac | Windows | 비고 |
|---|---|---|---|
| 바로 시작 · 업무로 시작 · 대화로 열기 | 1 / 2 / 3 | 1 / 2 / 3 | 3은 최근 대화의 첫 줄을 표시해요 |

Mac 은 ⌘ 를 누른 채 이름 위에 포인터를 잠시(0.6초) 두면 정의의 첫 줄들을 카드로 보여 줘요.

## ⌘↩ 와 ⌥⌘↩

⌥⌘↩ 는 언제나 ⌘↩ 의 "더 센" 쪽이에요. 메시지를 입력했으면 ⌘↩ 가 보내기(작업 중이면 대기열), ⌥⌘↩ 가 지금 턴을
멈추고 보내기예요. 입력란이 비어 있으면 ⌘↩ 가 가장 오래 기다린 권한 카드를 한 번 허용, ⌥⌘↩ 가 세션 동안 허용이에요.
입력 중에 ⌥⌘↩ 가 카드에 답하는 일은 없어요.

## 터미널처럼 쓰는 메시지 입력란

메시지 입력란은 터미널에서 Claude Code 를 쓰는 것처럼 동작해요(PROTOCOL §44.1).

- **Shift+Tab** 이 권한 모드를 기본 → 편집 바로 허용 → 계획 → 자동 → 기본 순서로 바꿔요. 이 모델에서 자동 모드를 쓸 수 없다고
  엔진이 알려 준 뒤에는 자동을 건너뛰어요. Claude 가 작업 중이면 이번 턴이 끝날 때 바뀌어요. 입력란 밖에서 Shift+Tab 은 예전처럼
  포커스를 앞 칸으로 옮겨요.
- 입력란 바로 아래 한 줄이 지금 모드를 보여 줘요: "⏵⏵ 자동 모드 (shift+tab 전환)", "⏸ 계획 모드 — 승인하면 자동 모드로 돌아가요
  (shift+tab 전환)". Claude 가 스스로 계획 모드에 들어가도 바로 바뀌어요.
- **Esc** 는 팔레트·프롬프트 기록이 먼저 쓰고, 그다음에는 작업 중인 턴을 멈춰요(⌘. / Ctrl+. 와 같아요). 불러온 프롬프트가
  보이는 동안에는 첫 Esc 가 쓰던 글을 돌려주고, 다음 Esc 가 턴을 멈춰요.
- 턴을 멈출 때 **기다리던 메시지가 있으면** 터미널처럼 돌려받아요(PROTOCOL §56.2): Claude 의 턴에 넣었지만 아직 읽지 않은
  메시지와 대기열 전체가, 보낸 순서대로 한 문단씩 쓰던 글 **앞**에 들어와요(멘션·이미지 포함). 대기열은 멈춘 뒤 이어서 보내지
  않아요. Claude 가 이미 읽은 메시지는 대화에 그대로 남고, 입력란 위에 그렇다고 알려 줘요. 중지 버튼과 ⌘. 는 예전처럼
  멈추기만 해요.
- 빈 입력란에서 **↑** 는 기다리던 메시지를 **모두** 돌려받아요 — 턴은 계속돼요. 기다리는 메시지가 없으면 이전 프롬프트예요.
- **↑ / ↓** 는 이전·다음 프롬프트를 불러와요. 쓰던 글이 있어도 되고, 그 글은 잃어버리지 않아요 — 가장 최근 프롬프트를 지나
  ↓ 를 누르거나 Esc 를 누르면 돌아오고, 프롬프트를 보내기 전까지 남아 있어요. 불러온 프롬프트를 고쳐도 기록을 오가는 동안
  고친 내용이 남아요. Mac 은 커서가 첫 줄·마지막 줄(화면에 보이는 줄)에 있을 때 불러오고, Windows 는 글이 있으면 ↑ 는 맨 앞,
  ↓ 는 맨 끝에서만 불러와요(첫 번째 누름이 커서를 그리로 옮겨요) — 길게 접힌 문단에서도 화살표로 줄을 옮길 수 있게요.
- **`/btw 질문`** 은 터미널처럼 side question이에요(PROTOCOL §56.1). Claude 가 작업 중이어도 바로 물어보고, 도구 없이 지금까지의
  대화로 답해요. 답은 입력란 위에 떠요 — 대화·대기열·프롬프트 기록에는 남지 않아요. Esc 로 닫고(턴을 멈추기 전에), 입력란이
  비어 있으면 ↩ · Space 로도 닫아요. `/btw` 만 입력하면 이 채팅의 마지막 답을 다시 보여 줘요.
- **⌃G / Ctrl+G** 는 터미널처럼 쓰던 메시지를 외부 편집기에서 열어요(PROTOCOL §56.3). `$VISUAL`, 없으면 `$EDITOR`(창을 여는
  편집기만 — vim·nano 같은 터미널 편집기는 건너뛰어요), 없으면 VS Code(`code --wait`), 없으면 시스템 기본 텍스트 편집기예요.
  저장할 때마다 입력란으로 들어오고, 편집기를 닫으면 끝나요. 입력란 위의 **완료** 는 저장한 내용을 두고, **취소** 는 ⌃G 전의
  메시지로 되돌려요.
- **`/mcp`** 는 터미널처럼 이 세션의 MCP 서버 목록을 입력란 위에 띄워요(PROTOCOL §56.4, 일반 채팅에서만 — 터미널 채팅은
  TUI 의 `/mcp`). ↑ / ↓ 로 고르고 ↩ 는 재연결(로그인이 필요한 서버는 로그인, 꺼진 서버는 켜기), ⌥↩ 는 켜기·끄기, ⌘↩ 는 그
  서버를 정의한 설정 파일, ⇥ 는 이름 완성, Esc 는 닫기예요. `/mcp ` 뒤에 적은 글자로 이름을 걸러요. `/mcp reconnect 이름`,
  `/mcp enable 이름`, `/mcp disable 이름` 을 ↩ 로 보내면 바로 실행하고 결과를 입력란 위에 알려 줘요(이름 대신 `all` 은 모든 서버). 작업 중인 행은
  스피너를 보이고, 입력란은 그동안에도 쓸 수 있어요. Windows 는 ⌥↩ 대신 Alt+Enter, ⌘↩ 대신 Ctrl+Enter 예요.
- 터미널 습관대로 친 **기본 명령**은 일반 채팅에서 앱 화면을 열어요(PROTOCOL §56.5): `/model` 모델 선택(`/model sonnet` 은
  바로 바꿔요), `/resume` 채팅 기록, `/rewind` 마지막 메시지 전으로 되돌리기, `/context` 컨텍스트와 compact, `/cost` 모델별
  비용, `/permissions` · `/config` 설정, `/agents` 에이전트 패널, `/memory` CLAUDE.md와 메모리, `/help` 키보드 단축키,
  `/status` 모델 · effort · 세션 · MCP 요약, `/rename` 채팅 이름 바꾸기, `/exit` 채팅 탭 닫기(기록에는 남아요). 팔레트에도
  한 줄 설명과 함께 보여요. 같은 이름의 내 명령·프로젝트 명령이 있으면 그쪽이 먼저예요. `/hooks` · `/vim` 처럼 터미널에만
  있는 명령은 보내지 않고 "이 명령은 터미널 채팅에서 써요" 와 **터미널 채팅으로 이어가기** 를 보여 줘요.
- **`/add-dir 경로`** 는 터미널처럼 프로젝트 밖의 디렉터리에서도 Claude 가 일하게 해요(PROTOCOL §67.1, 일반 채팅에서만 — 터미널
  채팅은 TUI 의 `/add-dir`). `~/…` 나 프로젝트 기준 상대 경로도 돼요. `/add-dir` 만 입력하면 폴더를 골라요. 추가한 디렉터리는
  입력란 위 **디렉터리 N** 칩에서 보고 빼거나 더할 수 있어요. 그 디렉터리의 수정은 리뷰에 diff 가 나오지 않아서 매번 권한
  카드로 승인받아요. Claude 가 일하는 동안에는 바꿀 수 없어요.
- **`!` 로 시작하는 메시지** 는 터미널의 bash 모드처럼 셸 명령이에요(PROTOCOL §67.2, 일반 채팅에서만). 입력란이 셸 모드 모양으로
  바뀌고, ↩ 는 Claude 에게 보내지 않고 프로젝트 폴더에서 명령을 실행해요. 출력은 대화에 남고, **다음 메시지와 함께** Claude 에게
  가요(Claude 는 그 명령을 다시 실행하지 않아요). 실행 중에는 Esc · 중지로 멈추고, 그동안 쓴 메시지는 대기열에서 기다려요. 명령이
  바꾼 파일은 다음 리뷰에 Claude 가 아닌 변경으로 나와요. 10분이 지나면 멈춰요.
- **⌃R / Ctrl+R** 은 터미널처럼 이 프로젝트에서 보낸 프롬프트를 찾아요(PROTOCOL §70.1, 일반 채팅에서만). 입력란 위에 검색 줄이
  뜨고, 입력하면 최근 것부터 걸러져요(찾은 글자는 강조). 다시 누르거나 ↑ 는 더 이전 것, ↓ 는 더 최근 것이에요. ↩ · ⇥
  (Windows 는 Enter · Tab) 는 찾은 프롬프트를 입력란에 넣기만 하고 보내지 않아요. Esc, 빈 검색에서 ⌫ 는 쓰던 글로 돌아가요.
  Windows 에서 Ctrl+R 은 입력란 밖에서는 예전처럼 새로고침이에요.
- **⌥T / Alt+T** 는 터미널처럼 이 채팅의 extended thinking 을 켜고 꺼요(PROTOCOL §70.4). Claude 의 다음 요청부터 적용되고,
  작업 중에도 돼요. 입력란 아래 줄의 뇌 아이콘이 상태를 보여 주고(꺼지면 "Thinking 꺼짐"), 눌러도 바뀌어요. Opus 5.5 ·
  Sonnet 5.5 · Haiku 5.5 · Fable 처럼 항상 생각하는 모델에는 효과가 없다고 알려 줘요. 새 채팅은 켜진 채로 시작해요.
- **⌃T / Ctrl+Shift+L** 은 터미널의 Ctrl+T 처럼 Claude 의 할 일 목록을 입력란 위에 보이거나 숨겨요(PROTOCOL §71.2, 일반 채팅에서만).
  Claude 가 TodoWrite · Task 도구로 만든 목록이 작업을 따라 바로 바뀌고(□ 대기, ◼ 진행 중, ✓ 완료), 한 번에 다섯 개까지
  보여요. `/todos` 도 목록을 보여 줘요. Claude 가 아직 목록을 만들지 않았으면 그렇다고 알려 줘요 — 할 일 도구가 없는 최신
  모델은 목록 없이 일해요. Windows 에서 Ctrl+T 는 예전처럼 새 채팅이에요.
- **`/export [파일]`** 은 터미널처럼 대화를 일반 텍스트로 내보내요(PROTOCOL §70.3). 파일 이름을 주면 그 파일(프로젝트 기준 상대
  경로도 돼요)에 쓰고, 이미 있는 파일은 덮어쓰지 않아요. `/export` 만 입력하면 **클립보드에 복사** 와 **파일로 저장…** 을
  고르는 창이 떠요. **`/copy [N]`** 은 Claude 의 마지막 답(`/copy 2` 는 그 전 답)을 클립보드에 복사해요.
- 터미널의 **`#` 메모리 단축키** 는 지금 Claude Code 에 없어서(빠른 명령은 `/` · `!` · `@` · `:` · `?` 뿐) 만들지 않았어요 —
  `#` 로 시작하는 메시지는 그대로 Claude 에게 가요. 메모리는 `/memory` 나 Claude 에게 기억해 달라고 말해서 남겨요(PROTOCOL §70.2).
